## Set up

From the repo root, install the workspace and compile every contract:

```bash
git clone https://github.com/midnightntwrk/midnight-examples.git
cd midnight-examples
yarn install && yarn compile
```

Then start a local Midnight network for this example. Make sure the Docker engine is running first:

```bash
cd examples/__name__
yarn env:up
yarn wait:dust
```
