# AGENTS.md: q2-ledger9

Instructions for agents working in this directory. Read [`README.md`](README.md),
[`DELIVERABLES.md`](DELIVERABLES.md) and the repo-root [`AGENTS.md`](../../AGENTS.md) first.

## What this is

A frozen snapshot of the Q2 stagenet acceptance suites for the compact-end-2-end dapps,
ported from the standalone `stagenet-q2` repo. It is a separate Yarn project, **not** an
mn-examples example:
- It is not in the root workspaces.
- It is not in the CI matrix.
- It is not generated by `yarn new:example`.

Its sibling `../q3-ledger9` covers the Q3 deliverables on a later ledger 9 stack.

## Rules

- **The pins are the Q2 snapshot.** compactc 0.33.0-rc.2, Midnight.js 5.0.0-beta.6,
  ledger-v9 1.0.0-rc.3 and the rest of the README stack table. They match what ran on
  stagenet, and `DELIVERABLES.md` reports results for exactly that stack. Do not bump them.
  If they need to move, it is a deliberate re-target with fresh runs and an updated
  `DELIVERABLES.md`.
- **Never touch the root install.** Do not edit the root `package.json` or `yarn.lock`, or
  `examples/`, from here.
- **Compile only with compactc 0.33.0-rc.2**, passed as `COMPACTC=/path/to/compactc yarn compile`.
  `compact update` cannot install it; it comes from the GitHub release (see README). The
  secp256k1/keccak contracts need `--feature-zkir-v3`, which `scripts/compile.mts` wires
  per contract.
- **Compile gaps are expected.** self-recursion, caller/Caller, axelar-gateway and
  recover-secp do not compile on rc.2, and their suites SKIP behind a GAP banner. Do not
  "fix" a gap by changing the contract: the suites are regression guards that run unchanged
  once the compiler catches up.
- **Run remote suites sequentially.** The deployer and relayer wallets are shared, and so is
  the single local proof server. `vitest.config.ts` already disables file parallelism.
  Never run two `test:stagenet` processes at once.
- **Ports collide with the mn-examples local network.** The proof server (6300) and the
  `local` endpoints (9944/8088) are the mn-examples ports. Stop that ledger 8 network before
  running anything here.
- **Never commit secrets or runtime state.** `.env.stagenet` (funded seeds) and the
  `midnight-level-db-*` private-state dirs are gitignored here. The root `.gitignore` does
  not cover them, so keep this directory's `.gitignore`. Only `.env.stagenet.example` is
  tracked.
- **Do not trust memory for Compact or SDK APIs.** These APIs are pre-release and differ
  from both the ledger 8 examples and q3-ledger9. Compile and run anything you add.
