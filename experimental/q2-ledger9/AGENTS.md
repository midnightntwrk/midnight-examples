# AGENTS.md: q2-ledger9

Instructions for agents working in this directory. Read [`README.md`](README.md),
[`COMPATIBILITY.md`](COMPATIBILITY.md), [`DELIVERABLES.md`](DELIVERABLES.md) and the repo-root [`AGENTS.md`](../../AGENTS.md) first.

## What this is

The Q2 stagenet acceptance suites for the compact-end-2-end dapps, ported from the
standalone `stagenet-q2` repo and moved to the Ledger 9 release stack in
[`COMPATIBILITY.md`](COMPATIBILITY.md). It is a separate npm project, **not** an
mn-examples example:
- It is not in the root workspaces.
- It is not in the CI matrix.
- It is not generated by `npm run new:example`.

## Rules

- **The pins are the Ledger 9 release stack in `COMPATIBILITY.md`.** Move them only as a
  set, together with that file and fresh runs. `DELIVERABLES.md` is the Q2 record: it
  reports the stagenet results on the original stack (compactc 0.33.0-rc.2, Midnight.js
  5.0.0-beta.6) and is not rewritten by a version move.
- **Install with npm 11.21+ and `--min-release-age 0` only for Midnight packages.** The
  `.npmrc` age gate holds third-party packages back 7 days; after an install, check new
  third-party lock entries and pin back any younger than that.
- **Never touch the root install.** Do not edit the root `package.json` or `package-lock.json`, or
  `examples/`, from here.
- **Compile with Compact 0.36.0** (`npm run compile`, which runs `compact compile +0.36.0`;
  `COMPACTC=/path/to/compactc` overrides it).
- **Compile gaps are expected.** self-recursion, axelar-gateway and recover-secp do not
  compile on 0.36.0, and their suites SKIP behind a GAP banner. Do not "fix" a gap by
  changing the contract: the suites are regression guards that run unchanged once the
  compiler catches up.
- **Run remote suites sequentially.** The deployer and relayer wallets are shared, and so is
  the single local proof server. `vitest.config.ts` already disables file parallelism.
  Never run two `test:stagenet` processes at once.
- **Ports collide with the mn-examples local network.** `npm run env:up` starts a Ledger 9
  node, indexer and proof server on the mn-examples ports (9944/8088/6300). Stop the
  examples' network before running anything here, and run `npm run env:down` after.
- **Never commit secrets or runtime state.** `.env.stagenet` (funded seeds) and the
  `midnight-level-db-*` private-state dirs are gitignored here. The root `.gitignore` does
  not cover them, so keep this directory's `.gitignore`. Only `.env.stagenet.example` is
  tracked.
- **Do not trust memory for Compact or SDK APIs.** These APIs are new in Ledger 9 and
  still moving between releases. Compile and run anything you add.
