# AGENTS.md — hello-world

**Verified against:** Compact language `0.23`, compiler `0.31.1`,
`@midnight-ntwrk/midnight-js-*` `4.1.1`, wallet SDK `1.2.0`, Node 22.

## What it teaches

The minimal end-to-end Midnight loop and an **environment smoke test**: compile a
trivial contract, stand up a local Midnight network, and run a test that deploys
and calls it. Also demonstrates the **fast-sync preseed** approach for quick
wallet sync (`src/fast-sync/`, `preseed/`).

## Layout

- `contract/hello-world.compact` — the contract source (committed).
- `contract/index.ts` — re-exports the generated contract + `zkConfigPath`.
- `src/` — TypeScript harness: `wallet.ts`, `providers.ts`, `config.ts`,
  `fast-sync/`, and `test/hw.test.ts`.
- `scripts/wait-for-dust.ts` — waits for DUST to accrue before tests.
- Funding the browser wallet on the local devnet is the repo-wide
  `npm run fund:wallet <mn_dust_…> [mn_addr_…]`, run from the repo root (`packages/fast-sync/scripts/fund-wallet.ts`),
  shared by every generated UI. It used to live here.
- `ui/` — browser frontend (its own workspace, `@midnight-ntwrk/example-hello-world-ui`).
  Midnight wiring lives in `ui/src/midnight/` (`contract.ts`, `providers.ts`,
  `hello-world-api.ts`); see `ui/README.md`. Most of `ui/` is rendered from
  `packages/mnkit/templates/ui/` and drift-checked (`npm run new:ui -- hello-world --check`). Only
  `hello-world-api.ts`, `hello-world-panel.tsx`, `message.test.ts` and the
  README are hand-written. `ui/AGENTS.md` explains `npm run new:ui`, which adds the
  same frontend to another example.

## Run

```bash
npm run compile
npm run env:up && npm run wait:dust
npm run test:local
npm run env:down
```

## Notes for agents

- The contract dir is `contract/` (singular) — normalized from the upstream
  `contracts/` during monorepo migration; `src/test/hw.test.ts` imports from
  `../../contract/index.js`.
- `contract/managed/` is generated by `npm run compile` and is gitignored.
- UI: `npm run dev` / `npm run build` / `npm run typecheck` / `npm run test:unit` from `ui/`.
  It has no `compile`/`test`/`test:local` scripts on purpose (root aggregates
  run on every workspace). Keep `vite` pinned to the hoisted 6.4.3 and the
  Midnight packages on the repo pins. The full wallet flow needs a human
  (wallet approvals), so there's no automated E2E test.
