# AGENTS.md — private-bid

**Verified against:** Compact language `0.23`, compiler `0.31.1`,
`@midnight-ntwrk/midnight-js-*` `4.1.1`, wallet SDK `1.2.0`, Node 22.

## What it teaches

- The docs guide "How to build a private smart contract" (midnight-docs PR
  #1434), rebuilt on this repo's harness. Keep the contract's logic in step
  with the guide; the comments here are deliberately fuller.
- Deciding per value what is public: a `sealed ledger` rule, a private circuit
  argument (`amount`), and a witness-supplied secret (`localSecretKey`).
- Disclosing the narrowest value: the bidder key is
  `disclose(persistentHash([purpose, kernel.self().bytes, secretKey]))`, never
  the key. The domain separator and the contract address make it unlinkable
  across deployments.
- `persistentCommit(amount, salt)` on the ledger without `disclose()`, and why a
  plain `persistentHash` of a guessable amount is not private. The salt is
  deterministic per bidder, which is safe only because of the
  one-bid-per-bidder check.
- Opening a commitment in `revealBid`, the single `disclose(amount)`.
- `sealed`: only the constructor (or a helper it calls) may write
  `minimumBid`. Writing it from an exported circuit is a compile error.

## Layout

- `contract/private-bid.compact` (committed), `contract/index.ts`
  (+ `contract/witnesses.ts` when the contract declares witnesses).
- `src/` harness; `src/test/private-bid.test.ts`.

## Run

```bash
yarn compile
yarn env:up && yarn wait:dust
yarn test:local
yarn env:down
```

## Notes for agents

- The tests share one deployment and one bidder and run in order (deploy, then
  a bid below the minimum is rejected, place, a duplicate is rejected, a wrong
  reveal is rejected, reveal). The rejected calls fail in local circuit
  execution, before proving, so they leave the ledger untouched and are fast.
- Verified on the local devnet only. The suite uses the shared `ALICE` wallet
  on remote networks, but `test:preprod`/`test:preview` have not been run.

- A browser UI is phase 2. Once `yarn test:local` is green, run
  `yarn new:ui private-bid` from the repo root, then build the use case into its
  seed files. See `templates/ui/AGENTS.md`.

- `contract/managed/` is generated by `yarn compile` and gitignored. The TS
  harness imports from it, so nothing type-checks until you have compiled at
  least once.
- The circuit-id union in `src/providers.ts` is derived from the compiled
  contract (`keyof ImpureCircuits`), so it never needs editing when circuits
  change.
- Remote-network wiring is shared, not copied. `src/wallet.ts` takes an optional
  `{ fastSync }` and the test resolves its wallet with
  `resolveWallet(network, role)` from `@midnight-ntwrk/example-fast-sync`. Do not
  write a per-example seed resolver; the shared one knows every suite's role
  names and reads the repo-root `.env.<network>`. See `FAST-SYNC.md`.
