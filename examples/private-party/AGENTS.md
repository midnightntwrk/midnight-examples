# AGENTS.md — private-party

**Verified against:** Compact language `0.23`, compiler `0.31.1`,
`@midnight-ntwrk/midnight-js-*` `4.1.1`, wallet SDK `1.2.0`, Node 22.

## What it teaches

- **Private data on chain** — keeping participant data private while proving
  facts about it.
- **Access control** on circuits.
- **Unshielded tokens (NIGHT)**.
- **DUST fee sponsorship** — a sponsor pays transaction fees on behalf of a
  user. See `docs/SPONSORSHIP.md`, `src/sponsor.ts`,
  `scripts/sponsor-service.ts`, and `src/test/sponsorship.test.ts`.

## Layout

- `contract/private-party.compact` (committed), `contract/index.ts`,
  `contract/witnesses.ts`.
- `src/` harness incl. `sponsor.ts`; tests `test/party.test.ts`,
  `test/sponsorship.test.ts`.
- `tutorials/` — the learning-path tutorial (step 2), synced to
  docs.midnight.network `/tutorials/private-party/`. Its titled code blocks
  quote `contract/` and `src/test/party.test.ts` verbatim, and CI checks them
  (`node scripts/check-tutorial-code.mjs`), so an edit to the quoted code
  means an edit to the tutorial in the same PR. DUST sponsorship is not in
  the tutorial; the docs cover it in `guides/dust-sponsorship`.

## Run

```bash
npm run compile
npm run env:up && npm run wait:dust
npm run test:local        # full suite
npm run test:sponsorship  # sponsorship flow only
npm run env:down
```

## Notes for agents

- The `.compact` source is committed (upstream gitignored it — fixed here).
- `contract/managed/` is generated and gitignored.
- `commitAddress(_secret, _address)` returns `persistentCommit(_address,
  _secret)`: the address is the committed value, the secret its salt.
  `guestCommitment` in `ui/src/midnight/private-party-api.ts` re-derives it
  and must keep the same order.
- `ui/` is the browser frontend, generated by `npm run new:ui private-party`.
  Its party rules (`partyView`, `actionError`) are in
  `ui/src/midnight/private-party-api.ts`, and
  `ui/src/__tests__/private-party-circuits.test.ts` replays this example's
  Node test in memory.
- **TODO:** the UI has not been run end to end with a wallet. The checklist
  is in `ui/README.md` ("TODO: end-to-end verification with a wallet"). Don't
  describe the UI as verified against a wallet until it's done, especially
  `checkIn`'s NIGHT payment and `claimFees`'s payout.
